Android-приложение на Python с графическим интерфейсом Kivy, предназначенное для автоматизации расчёта рецептур и количества ингредиентов при производстве мясной продукции и полуфабрикатов.

Проект разработан для решения практических задач в сфере общественного питания и используется в реальной работе.

📱 О проекте

При производстве мясной продукции часто возникает необходимость пересчитывать количество ингредиентов в зависимости от требуемого объёма готовой продукции.

RecipeBook позволяет автоматизировать этот процесс: достаточно выбрать рецепт, указать ингредиент и ввести необходимое количество в граммах. Программа автоматически рассчитает пропорции остальных ингредиентов и общий вес рецептуры.

Приложение разработано самостоятельно на Python с использованием Kivy и адаптировано для работы на Android.

✨ Основные возможности

Выбор рецепта — выбор необходимой рецептуры из списка.

Выбор ингредиента — возможность выбрать ингредиент, относительно которого будет выполняться расчёт.

Автоматический перерасчёт — вычисление количества всех ингредиентов на основе заданного веса выбранного ингредиента.

Расчёт общего веса — автоматическое суммирование массы всех ингредиентов.

Хранение рецептур — рецепты и их ингредиенты хранятся в отдельном JSON-файле.

Удобный интерфейс — графический интерфейс, разработанный с помощью Kivy.

Работа на Android — возможность использовать приложение непосредственно в рабочем процессе.
